# healthcare-patient-analysis


📊 Patient Waiting List Analysis Dashboard (Power BI)

📌 Project Overview

This project focuses on analyzing and tracking patient waiting lists across healthcare services using Power BI. The goal is to provide stakeholders with actionable insights into current waiting list status, historical trends, and detailed demographic breakdowns.

🎯 Problem Statement

Healthcare organizations often struggle to efficiently monitor and manage patient waiting lists due to fragmented data and lack of visibility.

This project aims to:

Track the current status of patient waiting lists
Analyze historical trends (2018–2021) for Inpatient and Outpatient categories
Provide granular insights by specialty and age group

🚀 Business Objectives

Enable data-driven decision-making for healthcare administrators
Identify trends and bottlenecks in patient flow
Improve resource allocation and operational efficiency

📂 Data Scope

Time Period: 2018 – 2021
Categories: Inpatient & Outpatient
Granularity: Specialty-level and Age-group analysis

📊 Key Metrics (KPIs)

Average Waiting Time
Median Waiting Time
Current Total Waiting List
Monthly Trend Analysis

🧩 Dashboard Features

Key KPIs (Average, Median, Total Waiting List)
Trend visualization over time
🔹 Detailed Analysis Page
Specialty-level breakdown
Age-group distribution
Deep dive into patient categories

🗂️ Data Sources

Data is collected using:

Excel / CSV files
Folder-based data repository (for automated refresh)
🔍 Data Understanding & Preparation
Performed data profiling (columns, types, structure)
Handled missing values and anomalies
Ensured data consistency and quality
⚙️ Tools & Technologies
Power BI (Dashboard & Visualization)
Excel / CSV (Data Source)
Power Query (Data Transformation)
DAX (Calculated Metrics & KPIs)

🔄 Data Refresh Strategy
Centralized folder used as a data repository
Enables easy updates and automated refresh in Power BI
📈 Key Insights Delivered
Identified peak periods of patient backlog
Highlighted high-demand specialties
Revealed age groups with longer waiting times

🏁 Conclusion

This dashboard provides a comprehensive view of patient waiting lists, helping healthcare stakeholders monitor performance, identify inefficiencies, and make informed operational decisions.
